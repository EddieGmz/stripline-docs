Channel strips

The 22 plugins Stripline supports, and how each one maps onto the console.

Shared counts the console's common controls the plugin has (input, filters, four EQ bands, compressor, gate, output). Own counts the additional controls only that plugin has that are mapped on the stripline's extra slots, or as automation-only parameters.
