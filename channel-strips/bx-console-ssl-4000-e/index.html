Knobs pass the plugin's own position through; the console prints the plugin's text. One Dyn On/Off switches compressor and expander/gate together: it drives COMP's on/off; GATE has none of its own. LPF, compressor threshold and the mid Q run downwards in the plugin: inverted so the console knobs rise.
