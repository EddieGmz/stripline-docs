Getting started

  1. Turn on OSC in REAPERThe console reaches REAPER's transport over OSC. In REAPER: Preferences → Control/OSC/web → Add → OSC (Open Sound Control), then set:
    • Mode: Configure device IP + local port
    • Device IP: 127.0.0.1, Device port: 9000
    • Local listen port: 8000
    • Pattern config: Default
    Press OK to save it; REAPER keeps it for every project.
  2. Open the consoleStart the Stripline app. It waits for bridges; nothing to set up.
  3. Add the bridge to a trackIn REAPER: FX → Stripline. Its window shows Connected to console.
  4. Scan oncePress Plugins…, then Scan for channel strips. Only the supported plugins are read, from the standard VST3 folders and any custom folder path you add.
  5. Choose the channel stripChoose plugin… lists them by company. The strip appears on the console in the plugin's colours.
  6. MixTurn knobs on the console or in the plugin window: both follow each other. Double-click a strip header to open the hosted plugin.

Around the console

  • VU / IN / FILT / EQ / DYN in the top bar show or hide those parts on every strip.
  • Tracks chooses which tracks are on the console. Alt-click a track to show only that one.
  • The transport follows REAPER: Space play/stop, Enter pause, R repeat.
  • The peak light on a VU stays on after a clip until you click the meter.
