Every channel strip, on one console.

Stripline puts channel strip plugins in your REAPER session side by side, like a console. Directly inspired by solutions such as Luna, SSL 360, CLA MixHub, and Harrison Mixbus

The bridge

A VST3 plugin you put on each track. It hosts your channel strip and passes audio straight through it.

The console

A desktop app showing every track as a strip: input, filters, EQ, dynamics, fader, meters.

Profiles

Built into the bridge. Each one maps a plugin's own parameters onto the console's knobs.

Premises (please read carefully)

  • This tool is almost entirely vibed-coded
  • I've experience as a Software Developer, but I'm not an Audio Plugin Developer
  • I'm passionate about music, but I'm not a mixing engineer
  • I use it almost exclusively for educational purposes, to play and practice doing mixes, and to learn how to listen for the different characteristics and nuances of the channel strips.

How it works

Each bridge connects to the console on your computer. Turn a knob on the console and the hosted plugin moves; turn it in the plugin window and the console follows. The console shows the plugin's own value text, so what you read is what the plugin does.

  • Audio runs only through the hosted plugin. The bridge adds no processing and reports the plugin's latency.
  • The bridge exposes 36 shared controls as its own parameters, so automation works the same whichever plugin is inside.
VST3 only, plugins with mapped profile only. See mapped Channel strips.
